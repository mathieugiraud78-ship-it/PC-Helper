PC HELPER V3 — NOUVELLE INTERFACE

Cette version restaure l’image de fond du PC dans l’interface.

LANCER
1. Double-cliquez sur Lancer_PC_Helper.bat
2. Le programme vérifie/installe les dépendances puis démarre PC Helper.

CREER LA VERSION EXE
1. Double-cliquez sur Creer_EXE_PC_Helper.bat
2. L’exécutable sera créé dans le dossier dist.
3. Le fichier pc_background.png est intégré automatiquement à l’EXE.

La version utilise pc_background.png comme image de fond.

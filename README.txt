- Informations & surveillance

- Monitoring CPU/RAM/disque/réseau
- Températures quand accessibles

- Démarrage / services / processus / périphériques

- Mode Technicien / Dépannage / Checklist / Minuteur

Installation :
pip install -r requirements.txt
python main.py

Notes :
Certaines fonctions dépendent des droits Windows, du matériel et des capteurs disponibles.
Le scanner réseau utilise des pings locaux et peut prendre quelques secondes.
Le nettoyage avancé doit être utilisé avec prudence.

PC HELPER V3 — KIT D'INSTALLATION

Cette version contient la nouvelle interface et le nouveau fond d'écran PC.
Le fond pc_background.png est utilisé par l'application.

INSTALLATION :
1. Décompressez le ZIP.
2. Double-cliquez sur Installer_PC_Helper.bat.
3. Le script installe les dépendances Python nécessaires.
4. Un raccourci « PC Helper V3 » est créé sur le Bureau.
5. L'application peut être lancée depuis ce raccourci.

IMPORTANT : ce kit installe la version Python. La compilation d'un véritable .exe Windows nécessite une machine Windows avec PyInstaller/Inno Setup. Le code et le fond sont déjà prêts pour cette compilation.
